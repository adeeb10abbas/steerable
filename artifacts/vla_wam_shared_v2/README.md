# VLA/WAM v2 evidence package

Use [`publication_manifest.json`](publication_manifest.json) for the bounded
set of article-ready assets. The rest of this directory preserves the audit
trail required to reproduce or challenge those assets.

| Directory | Purpose |
| --- | --- |
| `results/` | Compiled arena-separated summaries and figures |
| `figures/` | Frozen and current derived visualizations |
| `media/` | Selected behavioral and exposed-future videos |
| `pilot/` | Registries, compact cell evidence, hashes, and ledgers |
| `handoff/` | Environment snapshots and restart evidence |

Full raw rollouts, checkpoints, containers, and environments are intentionally
outside Git on persistent storage. Missing or latent-only future evidence is
not represented by placeholder zeros or substituted media.
