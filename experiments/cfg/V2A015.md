# V2-A015 — Cosmos3 and DreamZero guidance ablation

This is a separately labeled post-result pilot. It does not overwrite or rerun
either completed baseline. The machine-readable freeze is
`artifacts/vla_wam_shared_v2/pilot/post_result_cfg_ablation_v2a015_amendment.json`.

## Experimental cells

- Cosmos3 Nano Policy DROID: six new cells at `guidance=1.0`, compared with the
  preserved `guidance=3.0` V2-A011 result.
- DreamZero DROID derived action-guidance variant: six new cells at action
  scale `2.0`, with released video guidance fixed at `5.0`, compared with the
  preserved conditional-action V2-A007 result.

Both arms use seeds 8300--8302, exact static LEFT/RIGHT direct prompts, the
neutral DROID reset, viewport video, executed-action traces, and complete
future retention. Fixed-observation gates run before any behavioral cell.

DreamZero's released second branch is a fixed visual-quality negative prompt,
not empty text. The derived arm is therefore reported as **CFG-style
negative-branch action guidance**, not an official DreamZero action-CFG mode.

## DreamZero isolated overlay

Create a detached worktree from official commit
`ab790c198fbce33503358efbbd4187ce9a89adf3`, verify the target file SHA-256 is
`7193cd73423472aa252bee73bd80e0d673c89d773ec852e90f50154729b50845`, then
apply `experiments/dreamzero_droid/v2a015_action_cfg.patch`. Record the patched
file hash and worktree commit before model load. Never edit or use the
pre-existing port-5000 process.

The release gate first proves that action scale 1 is bit-identical to the
official action path. Scale 2 must also be deterministic on repeated LEFT,
prompt-sensitive between LEFT and RIGHT, finite, and contract-valid. Its
same-input latent video is compared with scale 1 but is not required to match:
the changed action latent can feed back through later joint-attention steps.

## Claim boundary

Each arm has its own six-cell DROID denominator. The pilot is descriptive at
three paired seeds. Report paired changes, signed requested margins, trajectory
quality, and future/execution agreement; do not call an unpowered difference a
general performance gain. Missing futures are not zeros, and DROID is never
pooled with RoboTwin.
