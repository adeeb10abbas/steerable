# Figure Assets

The PDF and PNG assets in this directory are regenerated by `scripts/make_summary_figures.py` at their final IEEE placement sizes. `main.tex` uses the vector PDF versions.

- `checkpoint_screen`: complete Phase-A directional-success screen: five DROID/RoboLab rows with 27 matched pairs each and three RoboTwin rows with 63 pairs each. The arenas are shown separately and are never pooled.
- `reference_inversion`: C002 endpoint separation and requested-depth contrasts over 341 independent reset blocks, including canonical-to-inverted success counts.
- `reflection_core`: three-checkpoint requested-depth reflection interactions and the pi0.5 completion inversion.
- `lateral_sweep`: seven-position Nano reference-object sweep, with continuous placement and binary success.
- `symmetry_core`: matched 27-seed E004 core interactions with 95% intervals.
- `failure_composition`: matched E004 pi0.5 endpoint failure counts over 341 seed pairs per scene.

Values and claim boundaries are indexed in `EVIDENCE_MAP.md`. Before submission, regenerate from the pinned environment and compare labels, intervals, cohorts, seeds, and denominators against the referenced decision memos.
