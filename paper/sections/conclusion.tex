\section{Conclusion}
\label{sec:conclusion}

Binary LEFT/RIGHT task success does not, by itself, measure language grounding. In our matched trials, canonical direction tokens redirect control, but scene configuration can reverse which direction completes successfully, and reference inversion can remove the expected response. Directional benchmarks should therefore report prompt-conditioned action change, signed endpoint ordering, continuous placement, binary completion, scene controls, and semantic-form controls separately before assigning a failure to weak language grounding.
